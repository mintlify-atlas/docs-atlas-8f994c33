## What is Melange?

Melange is an **authorization compiler**. It takes your authorization model written in the [OpenFGA](https://openfga.dev) DSL and compiles it into specialized PL/pgSQL functions that run directly inside your PostgreSQL database.

Like Protocol Buffers compiles `.proto` files into serialization code, Melange compiles `.fga` files into optimized SQL functions for [Zanzibar](https://research.google/pubs/pub48190/)-style relationship-based access control.

```
schema.fga  ──melange migrate──►  PostgreSQL functions
                                  check_permission()
                                  list_accessible_objects()
                                  list_accessible_subjects()
```

## How it's different

Traditional authorization systems require you to sync your application data to a separate service. Melange takes a different approach: **it's a compiler, not a runtime service**.

## How it works

**Compile time** — when you run `melange migrate`, the compiler:

1. Parses your OpenFGA schema
2. Analyzes relation patterns (direct, union, exclusion, computed)
3. Computes transitive closures for role hierarchies
4. Generates specialized SQL functions for each relation
5. Installs the functions into PostgreSQL

**Runtime** — permission checks are simple SQL function calls:

- `check_permission()` calls the generated functions
- Functions query the `melange_tuples` view you define over your domain tables
- PostgreSQL's query planner optimizes the specialized functions
